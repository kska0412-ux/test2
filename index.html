Market Analysis

市場分析の4つの着眼点

01
市場の共通価値観

界隈で当たり前とされている考え方・美徳を把握する

02
市場の歪み

ターゲットの偏り、質の低い商品が売れている等のギャップ

03
刺さるフレーズ

界隈特有の共通言語、刺さる実績表現、"すごい"の基準値

04
読者の欲求や恐怖

界隈特有の悩み・欲求・不満を捉える

着眼点 01

市場の共通価値観

例：ナンパ界隈

「なるべく安く時間をかけずに抱けるといい」
→ コスパの良さが美徳
→ 風俗・アプリは仮想敵にされる

活用法

  • ・同調してファンを獲得
  • ・批判的な立場でポジションをとる
  • ・仮想敵批判やコンセプト作りに活用

着眼点 02

市場の歪みを見つける

ターゲットの偏り

例：ナンパ界隈は専門用語が多く
ガチ初心者が取りこぼされていた

→ 初心者向けに出したら見事に伸びた

商品の質と売上のギャップ

ライバルの商品がしょぼいのに
めちゃくちゃ売れている

→ 高クオリティ商品をぶち込めば跳ねる

着眼点 03

刺さるフレーズと基準値

ナンパ界隈

  • 100即 → まだ初心者
  • 600〜800即 → ようやく注目

ビジネス界隈

  • 月100万円 → すごい人と認知
  • 月1,000万円 → トップクラス
何に価値を置く界隈なのか、どんな実績表現が刺さるのか、
"すごい"となる基準値を理解しておく

Market Analysis

市場分析の6ステップ

01
大手アカウントの特定

キーワード検索で1〜3万フォロワー層を探す

02
芋づる式で競合を洗い出す

絡み・引用から周辺の発信者を発見

03
伸びてるアカウントを探す

フォロワー数 ÷ ツイート数が大きい＝運用上手い

04
商品 / 発信内容を見る

実績・キーワード・テーマを分析

05
情報を取り出す

8項目で競合商品を徹底分析

06
共通項を取り出す

競合の共通項＝市場の常識を把握

Market Analysis

稼げてる旬の発信者の特定方法

「売れてる人を特定できるか」で市場分析の全てが決まる
1
ローンチを追う

Tipsの販売部数を5分おきに確認。売り方・導線・商品も全部買って分析

2
noteのいいね数から予測

いいね数 × 1.5〜2倍 = 販売部数。価格をかけて想定売上を算出

3
オフラインで聞く

オフ会で得られるリアル情報が最も価値が高い。発信してないと呼ばれない

Market Analysis

洗い出す3種類の発信者

TYPE A

大手発信者

界隈の常識・主流な考え方がわかる

TYPE B

伸びてる発信者

今のトレンド・求められてるものがわかる

TYPE C

普通の発信者

市場全体の雰囲気・平均値が捉えられる

各5人ずつ見つけて細かく分析する

Market Analysis — STEP 05

競合商品の分析8項目

  • どんな実績を主張してるか
  • どんなキーワードを使ってるか
  • どんな内容が書いてあるか
  • 商品テーマは何か
  • 商品の悪い点、不満な点
  • 仮想敵として何を批判してるか
  • どんな欲求や悩みに訴求してるか
  • どんな恐怖に訴求してるか

5個くらい商品を読めば、その市場の常識になっている知識が何かわかってくる。
悪い点・不満な点のメモが、自分の商品作り・仮想敵批判の材料になる。

Market Analysis

仮想敵批判の戦略

順張り戦略

競合と同じ仮想敵を批判して
共感を獲得する

例：「1垢だけの実績で再現性を謳ってるやつ多すぎ」

逆張り戦略

競合の主張に反論して
独自ポジションを確立する

例：「強者に媚びるの無駄って言ってるやつエアプやろ」

よく出てくる主張 ＝ 論争になりやすいテーマ → 発信のネタになる

Market Analysis — STEP 06

共通項を取り出す

競合の発信の共通項 ＝ 市場の常識

複数の競合が同じことを言っている → それが界隈のスタンダード

このベースを理解した上でコンセプト作り・発信を行う

Customer Analysis

顧客分析：N1分析の考え方

伸びてる理由は顧客のことをめちゃくちゃ理解してるから

顧客を深く理解することで実現できること：

  • "その人"にはクソほど耳が痛い内容のツイートが作れる
  • 共感しまくるツイートができる
  • 損失回避を刺激する訴求ができる

Customer Analysis

顧客分析の基本は人と会うこと

実際に会って掘り下げる質問

  • なぜ始めたのか（動機）
  • なぜうまくいかないのか（課題）
  • 何が知りたいのか（欲求）
  • どこでつまずいているのか（ボトルネック）

Customer Analysis

SNSでの顧客リサーチ手法

1
競合商品の購入者を追う

「〇〇さんの商品買いました！」と言ってる人の普段のツイートを見る

→ 興味・欲求・悩み・不満が見える

2
YouTubeコメント欄

業者が少なく素直な感想が書かれている。情報に疎い初心者層の本音がわかる

→ 「34歳でもできますか」等のリアルな声

3
LINEオープンチャット

匿名だからこそ本音が書かれている。特にビジネス系で有効

→ 顧客の本当の欲求を把握

Customer Analysis

見落としがちな重要な視点

読者の99%は超・初心者

情報発信してると、変なプライドから中上級者向けの発信をしてしまいがち。
これをやると必ず売上やフォロワーの伸びが落ちる。

顧客視点で発信者がどう見えるかを常に意識する

例：女性アダルト系をフォローしてる男 → 役立つからではなくヤれそうだから見ている
→ 顧客の"本音の動機"を理解して発信に活かす
